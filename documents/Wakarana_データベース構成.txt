_/_/_/_/ データベース _/_/_/_/
[]内はSQLiteでのデータ型

テーブル `wakarana_users` ・・・ ユーザーの基本情報を記録するテーブル
  `user_id` varchar(60) [TEXT COLLATE NOCASE] (NOT NULL PRIMARY KEY) ユーザーID(半角英数字及びアンダーバーが使用可能、大文字小文字区別なし)
  `password_hash` text [TEXT] (NOT NULL) パスワードのハッシュ値を含むModular Crypt Formatの文字列(またはパスワードのSHA-512方式のハッシュ値)
  `user_name` varchar(240) [TEXT COLLATE NOCASE] ユーザー名(ハンドルネームや氏名など、空欄可)
  `user_created` timestamp [TEXT] (NOT NULL) アカウントの作成日時
  `last_updated` timestamp [TEXT] (NOT NULL) アカウント情報の最終更新日時
  `last_access` timestamp [TEXT] (NOT NULL) そのアカウントの最終利用日時
  `status` smallint [INTEGER] (NOT NULL) アカウントが使用可能か停止されているか(0:停止, 1:有効, -1:未承認)
  `totp_key` varchar(16) [TEXT] TOTPワンタイムパスワード生成キー
  `used_invite_code` varchar(16) [TEXT] 登録時に使用した招待コード
  
  UNIQUE INDEX `wakarana_idx_u0` LOWER(`user_id`) ※PostgreSQLのみ
  INDEX `wakarana_idx_u1` LOWER(`user_name`) [`user_name`]
  INDEX `wakarana_idx_u3` `user_created`
  INDEX `wakarana_idx_u4` `used_invite_code`, `user_created`
  
 ※`last_access`については、処理の高速化の観点から、あえてインデックスを指定しない。


テーブル `wakarana_user_email_addresses` ・・・ ユーザーのメールアドレスを記録するテーブル
  `user_id` varchar(60) [TEXT COLLATE NOCASE] (NOT NULL) ユーザーID
  `email_address` varchar(254) [TEXT] (NOT NULL) メールアドレス
  `is_primary` boolean [INTEGER] (NOT NULL) プライマリメールアドレスか否か
  
  PRIMARY KEY `user_id`, `email_address`
  INDEX `wakarana_idx_e1` `user_id`, `is_primary`
  INDEX `wakarana_idx_e2` `email_address`


テーブル `wakarana_user_custom_fields` ・・・ ユーザーの文字列型カスタムフィールドを記録するテーブル
  `user_id` varchar(60) [TEXT COLLATE NOCASE] (NOT NULL) ユーザーID
  `custom_field_name` varchar(60) [TEXT] (NOT NULL) カスタムフィールド名
  `value_number` smallint [INTEGER] (NOT NULL) カスタムフィールド値が複数ある場合の並び順番号(1から付番)
  `custom_field_value` text [TEXT] カスタムフィールド値
  
  PRIMARY KEY `user_id`, `custom_field_name`, `value_number`
  UNIQUE INDEX `wakarana_idx_c1` `user_id`, `custom_field_name`, `custom_field_value`
  INDEX `wakarana_idx_c2` `custom_field_name`, `custom_field_value`


テーブル `wakarana_user_custom_numerical_fields` ・・・ ユーザーの数値型カスタムフィールドを記録するテーブル
  `user_id` varchar(60) [TEXT COLLATE NOCASE] (NOT NULL) ユーザーID
  `custom_field_name` varchar(60) [TEXT] (NOT NULL) カスタムフィールド名
  `value_number` smallint [INTEGER] (NOT NULL) カスタムフィールド値が複数ある場合の並び順番号(1から付番)
  `custom_field_value` double precision [NUMERIC] カスタムフィールド値
  
  PRIMARY KEY `user_id`, `custom_field_name`, `value_number`
  UNIQUE INDEX `wakarana_idx_cn1` `user_id`, `custom_field_name`, `custom_field_value`
  INDEX `wakarana_idx_cn2` `custom_field_name`, `custom_field_value`


テーブル `wakarana_recovery_codes` ・・・ ユーザーの2要素認証失敗時用リカバリコードを記録するテーブル
  `user_id` varchar(60) [TEXT COLLATE NOCASE] (NOT NULL) ユーザーID
  `recovery_code` varchar(24) [TEXT] (NOT NULL) 2要素認証失敗時用リカバリコード
  
  PRIMARY KEY `user_id`, `recovery_code`


テーブル `wakarana_sessions` ・・・ ユーザーのセッション情報を記録するテーブル
  `session_id` varchar(16) [TEXT] (NOT NULL PRIMARY KEY) セッションID
  `token` varchar(43) [TEXT] (NOT NULL UNIQUE) セッショントークン(/dev/urandom由来の32バイト乱数バイナリをBase64エンコード(+と/の代わりに-と_)したもの)
  `user_id` varchar(60) [TEXT COLLATE NOCASE] (NOT NULL) ユーザーID
  `token_created` timestamp [TEXT] (NOT NULL) セッショントークンの生成日時
  `ip_address` varchar(39) [TEXT] (NOT NULL) 利用者のIPアドレス
  `operating_system` varchar(30) [TEXT] セッショントークンを割り当てられた端末のOS名(「GNU/Linux」、「Android」等)
  `browser_name` varchar(30) [TEXT] セッショントークンを割り当てられた端末のブラウザ名(「Chrome」、「Firefox」等)
  `last_access` timestamp [TEXT] (NOT NULL) セッションの最終アクセス日時
  
  INDEX `wakarana_idx_s1` `token_created`
  INDEX `wakarana_idx_s2` `user_id`, `token_created`
  
 ※`last_access`と`ip_address`については、処理の高速化の観点から、あえてインデックスを指定しない。

テーブル `wakarana_authentication_logs` ・・・ ユーザーによる各種試行のログを保存するテーブル
  `ip_address` varchar(39) [TEXT] (NOT NULL) 利用者のIPアドレス
  `authentication_id` varchar(254) [TEXT COLLATE NOCASE] ユーザーIDまたはメールアドレス
  `authentication_type` varchar(60) [TEXT] (NOT NULL) 試行の種類
  `succeeded` boolean [INTEGER] 試行に成功したか否か(成功・失敗の概念が存在しない試行の場合はNULL)

  `authentication_datetime` timestamp [TEXT] (NOT NULL) 試行が行われた日時(マイクロ秒単位)
  
  INDEX `wakarana_idx_a1` `authentication_id`, `authentication_datetime`
  INDEX `wakarana_idx_a2` `authentication_datetime`

  `failure_count` integer [INTEGER] (NOT NULL) 現時点までの連続失敗回数

  INDEX `wakarana_idx_fa1` `last_authentication_datetime`

テーブル `wakarana_invite_codes` ・・・ ユーザー招待コードを保存するテーブル
  `invite_code` varchar(16) [TEXT] (NOT NULL PRIMARY KEY) 招待コード
  `is_active` boolean [INTEGER] (NOT NULL) 有効か否か
  `user_id` varchar(60) [TEXT COLLATE NOCASE] コードを発行したユーザーのユーザーID(現存するユーザーが発行したコードでない場合はNULL)
  `code_created` timestamp [TEXT] (NOT NULL) コードの生成日時
  `code_expire` timestamp [TEXT] コードの有効期限(NULLの場合は無期限)

  `usage_count` integer [INTEGER] (NOT NULL) コードが使用された回数
  
  INDEX `wakarana_idx_i1` `is_active`, `code_expire`
  INDEX `wakarana_idx_i2` `code_created`
  INDEX `wakarana_idx_i3` `is_active`, `code_created`
  INDEX `wakarana_idx_i4` `user_id`, `code_created`
  INDEX `wakarana_idx_i5` `user_id`, `is_active`, `code_created`
  INDEX `wakarana_idx_i6` `usage_count`, `is_active`
